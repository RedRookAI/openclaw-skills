# Baidu ERNIE

**Observed in older fiction:** ERNIE 4.5 300B A47B mixed dialogue attribution styles in the December 2025 dataset. That finding describes a stylistic choice, not a quality defect. [Source](https://github.com/lechmazur/writing_styles).

**Editing response, if present:** Normalize dialogue presentation only if inconsistent attribution confuses the reader or the user requests a house style. Keep deliberate variation and speaker meaning. This evidence does not justify a distinctive stock-phrase or humor blacklist for ERNIE, especially for Chinese-language writing. For ordinary correspondence or newer versions, use the general pass and the user's language conventions.
