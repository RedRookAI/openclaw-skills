# OpenClaw Skills

Skills and copy-and-paste prompts for everyday problems with AI agents.

| Skill | What it does |
| --- | --- |
| [Remove AI slop](skills/remove-ai-slop/README.md) | Makes AI drafts read naturally. Cuts canned phrasing, forced jokes, and repetitive rhetoric. |

## Use a skill

Download its ZIP from [Releases](https://github.com/RedRookAI/openclaw-skills/releases), then extract the skill folder into your OpenClaw workspace's `skills/` directory. [OpenClaw setup](https://docs.openclaw.ai/tools/skills).

Each skill also includes a standalone prompt you can paste into a chat.
